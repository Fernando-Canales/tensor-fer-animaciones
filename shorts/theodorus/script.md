# Guión

Si tenemos dos rectas de longitud 1, que se cruzan formando un ángulo recto, la hipotenusa medirá raíz de 2


Sobre esta hipotenusa, creamos otro cateto de longitud 1. Así obtenemos otro triángulo, cuay hipotensusa mide raíz de 3. 

Si repetimos el proceso con este nuevo triángulo, y obtenemos otra hipotenusa, esta medirá raíz de 4. 


Si seguimos igual con este proceso de que cada hipotenusa sea el cateto del siguiente triángulo, y le sumemos un cateto de 1, obtenemos longitudes que son raíces de los enteros siguientes:
Raíz de 8… raíz de 9… raíz de 10… raíz de 11… y así para todos los números

Este proceso puede seguir para siempre, y la hipotenusa de cada triángulo nos da la raíz de un entero más y más grande.

Esta es la espiral de Teodoro, una figura geométrica formada por una sucesión de triángulos rectángulos pegados uno tras otro
